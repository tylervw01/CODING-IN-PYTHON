Preview: Sample 2

ample 2 shows how Python can print styled text by combining strings into a framed output. Instead of a plain greeting, the program builds a box of asterisks and spaces around the phrase “Good Morning!”, teaching you how to use variables and print() to create simple console designs.

Hello.py


# greeting = 'Good Morning'
# print(greeting)

print1 = "******************************************"
print2 = "*                                        *"
print3 = "*                                        *"
print3 = "*             Good Morning!              *"

print(print1)
print(print2)
print(print3)
print(print2)
print(print1)
